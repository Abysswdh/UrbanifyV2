# Urbanify

![Urbanify Logo](Assets/3.png)

## 🚀 Tentang Urbanify

**Urbanify** adalah website edukasi interaktif yang bertujuan untuk meningkatkan pemahaman mengenai pengelolaan kota dan lingkungan yang lebih cerdas.

Kata "Urbanify" diambil dari gabungan "Urban" (perkotaan) dan akhiran "-ify" (membuat menjadi), yang berarti proses mengubah atau meningkatkan aspek perkotaan untuk menciptakan kota yang lebih baik, efisien, dan berkelanjutan. Website ini membahas elemen-elemen utama pembentuk Smart City untuk memberikan wawasan mendalam kepada pengguna.

## ✨ Fitur & Topik Utama

Urbanify menyajikan materi edukasi yang terbagi dalam beberapa topik utama:

- **Smart City**: Konsep perkotaan yang menggunakan teknologi untuk mengelola kota dengan lebih efisien.
- **Smart Environment**: Lingkungan yang dilengkapi teknologi canggih untuk mengoptimalkan sumber daya.
- **Urban Greenspace**: Area terbuka hijau di kawasan perkotaan untuk keseimbangan ekosistem.
- **IoT Application**: Integrasi internet dan sensor dalam fasilitas kota.
- **Citizen Engagement**: Keterlibatan aktif warga dalam pengambilan keputusan publik.
- **Gallery**: Kumpulan visualisasi penerapan konsep Smart City.
- **Quiz Interaktif**: Fitur kuis di setiap topik untuk menguji pemahaman pengguna.

## 📁 Struktur Proyek

```
Urbanify/
├── Assets/               # Gambar, video, logo, dan dokumen PDF
├── _Page/                # Halaman-halaman sub-topik
│   ├── About/            # Halaman About Us
│   ├── CitizenEngagement/# Materi Citizen Engagement
│   ├── Contact/          # Halaman Contact
│   ├── Gallery/          # Halaman Gallery
│   ├── IoT/              # Materi IoT Application
│   ├── SmartCity/        # Materi Smart City
│   ├── SmartEnvironment/ # Materi Smart Environment
│   └── UrbanGreenspace/  # Materi Urban Greenspace
├── index.html            # Halaman Utama (Landing Page)
├── script.js             # Logika JavaScript utama
└── style.css             # Stylesheet global
```

## 🛠️ Teknologi

- **HTML5**: Struktur konten web semantik.
- **CSS3**: Desain modern dan tata letak responsif.
- **JavaScript**: Interaktivitas, navigasi dinamis, dan logika kuis.
- **AOS (Animate On Scroll)**: Animasi elemen halus saat digulir.
- **Font Awesome**: Ikon vektor untuk antarmuka yang intuitif.
- **Google Fonts**: Tipografi modern menggunakan font *DM Sans* dan *Manrope*.

## 📝 Cara Menggunakan

1. Clone repository ini:
   ```bash
   git clone https://github.com/Abysswdh/UrbanifyV2.git
   ```

2. Buka folder proyek dan jalankan `index.html` di browser Anda.

3. Jelajahi materi edukasi melalui navigasi menu atau bagian-bagian di halaman utama.
